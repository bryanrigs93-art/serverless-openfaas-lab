# Serverless with OpenFaaS / Serverless con OpenFaaS

## English

This is my lab project for **Introduction to Cloud Computing**. I used Docker Desktop, Kubernetes, Helm, OpenFaaS, and Python to prepare and run a simple serverless registration function.

### What the function does
- Shows a registration form using an HTTP GET request.
- Receives a name, last name, and email through an HTTP POST request.
- Generates a JSON file with a unique UUID, execution date, container information, and a SHA-256 hash.

### Tools
Python · Docker Desktop · Kubernetes · Helm · OpenFaaS · PowerShell · Visual Studio Code

### Project structure
The files are kept inside `laboratorio-serverless/`, following the lab submission instructions. The downloaded JSON is the evidence generated by running the function.

### Local test
The Python function was packaged into the `registro-serverless:v1` Docker image and run locally. The OpenFaaS stack configuration is included in the project.

## Español

Este es mi proyecto de laboratorio de **Introducción al Cómputo en la Nube**. Utilicé Docker Desktop, Kubernetes, Helm, OpenFaaS y Python para preparar y ejecutar una función de registro con el modelo Serverless.

### ¿Qué hace la función?
- Muestra un formulario de registro mediante una solicitud HTTP GET.
- Recibe nombre, apellido y correo electrónico mediante HTTP POST.
- Genera un archivo JSON con un UUID único, fecha de ejecución, información del contenedor y una firma SHA-256.

### Herramientas
Python · Docker Desktop · Kubernetes · Helm · OpenFaaS · PowerShell · Visual Studio Code

### Estructura del proyecto
Los archivos están organizados dentro de `laboratorio-serverless/`, según las indicaciones de entrega. El JSON descargado es la evidencia generada al ejecutar la función.

### Prueba local
La función Python se empaquetó en la imagen Docker `registro-serverless:v1` y se ejecutó localmente. También se incluye la configuración para OpenFaaS.
